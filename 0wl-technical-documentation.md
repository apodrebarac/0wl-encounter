## Overview

This document provides a technical record of a body of practice-led PhD research in which recurrent neural networks (RNNs) are trained on intimate personal archives and physiological data to generate poetry. The practice spans from the first text generator F0x (2017) to the current 0wl system, encompassing EEG-driven performances, tree-mapping, cross-species neural experiments, and iterative model development.

## Project 1: F0x (2017–2019)

### Concept
F0x was the first text generator in the practice — named for the "0" that would carry forward through all subsequent models. Trained on the translated and anonymised letters of the author's grandfather, it operated as a *wounded archive*: data shaped by grief, displacement, and the irreversibility of loss. The model was intentionally kept fragile. Rather than being repaired or retrained when it began to fail, it was allowed to collapse — its final outputs (stutters, loops, blank sequences, ASCII ruins) treated as a form of algorithmic mourning.

### Corpus
- **Source**: Personal letters written by the author's grandfather
- **Language**: Original language (Croatian/Yugoslav) → translated to English
- **Pre-processing**: Anonymisation prior to training (names, locations removed as an ethical step)
- **NLP tools used**: NLTK (Python Natural Language Toolkit)
  - `from nltk.stem import PorterStemmer, WordNetLemmatizer`
  - Stemming and lemmatisation applied to normalise text before training

### Model
- **Architecture**: Recurrent Neural Network (RNN), character-level LSTM
- **Library**: `textgenrnn` (Python)
- **Training approach**: Intentionally unstable — the model was not optimised for coherence. Fragmentation and drift were considered meaningful outputs rather than errors
- **Collapse**: The model was allowed to fail rather than be retrained; its terminal outputs were preserved

### Outputs
- Fragmented poetry, increasingly incoherent over the model's lifetime
- **Ceiling installation** (January 2019) of final F0x poetry fragments
- **Venice Biennale 2024** — Croatian Pavilion, within Vlatka Horvat and Antonia Majaca's project *By the Means at Hand*: a booklet of F0x's saved outputs (fragmented conversations, stutters, ASCII ruins, nonsensical sequences) exhibited as a quiet diary of diasporic adaptation and unease
- Final poem beginning: *"Devotion in a voice and processing of being..."*

### Key Technical Notes

## Project 2: Immigrant and a Tree — Dual Archive System (March–May 2019)

### Concept
A dual mapping system in which the internal nervous system (brain/body/EEG) and the external nervous system (city/trees/displacement) were constructed simultaneously and trained together as a binary dataset. The two archives produced two RNN models (RNN₀ and RNN₁) and two poetry books (Book 0 and Book 1 / *am*).

The work closed recursively: poetry generated by the RNNs was read aloud to the trees that had been assigned the original EEG fragments — returning machine-processed language to its non-human origin point.

---

### Internal Archive: EEG Performance

#### Hardware
- **EEG system**: PLUX biosignalsplux EEG sensor kit
- **Additional hardware**: Arduino board (mapped brain activity in real time alongside EEG)
- **Software**: OpenSignals (PLUX) — multi-channel EEG data visualisation and export
  - Export format: plain text / `.txt` sessions
  - Column structure: `[sequence, digital, ch1, ch2, ch3, ...]` (EEG channel = last column of sensor data)

#### Performance Protocol
- **Sessions**: 4 × 4 hours (total 16 hours of EEG data + simultaneous writing)
- **Location**: Writing on a wall — stream of consciousness, durational and exhaustive
- **Simultaneous recording**: EEG sensors active throughout all writing sessions
- **Intent**: Push language to the point where coherence thins and the body's cognitive architecture becomes visible through its own fragmentation

#### Data Processing (EEG Spike Detection)
```python
from opensignals import load_session
import numpy as np

# Load EEG session
eeg = load_session('session_01.txt')
# OpenSignals exports: [sequence, digital, ch1...]
# EEG channel = last column of sensor data

# Detect neural spikes
threshold = np.mean(eeg) + 2.0 * np.std(eeg)
spike_indices = np.where(eeg > threshold)[0]

# Filter: keep only onset of each spike (min 50-sample gap)
events = [s for i, s in enumerate(spike_indices)
          if i == 0 or s - spike_indices[i-1] > 50]
```

#### Word Fragment Extraction
After each four-hour session, the words and phrases that survived the endurance of continuous inscription were gathered as *residues*. These were not algorithmically selected from EEG spikes — they were the physically surviving written fragments from the wall, the linguistic equivalent of what remained after exhaustion. Examples: `"displaced"`, `"root"`, `"still"`, `"glass"`, `"waiting"`, `"breath"`, `"foreign"`, `"threshold"`, `"tremor"`, `"silence"`.

These fragments became the **internal corpus** (RNN₁ training data).

### External Archive: Tree Mapping (*Immigrant and a Tree*)

#### Process
- **Location**: London, primarily Stepney / Whitechapel / East London (Mile End area)
- **Scope**: 700+ non-native trees documented across walking routes through the city
- **Each tree**: Assigned a word drawn from the EEG performance fragments
- **Rationale**: Non-native trees — growing in foreign soil, adapted to displacement — were treated as the external nervous system; each received a word carrying neural and linguistic residue from the EEG performance

```python
# Assign EEG fragments to London trees
tree_words = {}
for i, tree in enumerate(london_trees):
    word = fragments[i % len(fragments)]
    tree_words[tree.location] = word
    # tree ← word: intra-active encounter
    # neither pre-exists unchanged (Barad, 2007)
```

#### Output
- A geographic map of East London with 700+ tree locations marked
- A corpus of tree-location ↔ word-fragment pairs (external training data)
- Title: *Immigrant and a Tree — Mapping the External Nervous System*, walking performance, 2019

### RNN Training: Dual Archive (Binary Dataset)

Both archives — internal (EEG fragments) and external (tree-word sequences) — were fed into the RNN system together, forming a *binary dataset*.

| Model | Archive | Corpus | Output Book |
|-------|---------|--------|-------------|
| RNN₀ | External | Tree-word sequences from Immigrant and a Tree | **Book 0** (F0x) |
| RNN₁ | Internal | EEG neural writing fragments | **Book 1** (*am*) |

```python
from textgenrnn import textgenrnn

# Train on combined dual corpus
textgen = textgenrnn()
textgen.train_from_file(
    'combined_corpus.txt',
    num_epochs=50,
    rnn_size=128,
    rnn_layers=2,
    word_level=False,
    new_model=True
)

# Generate poetry at varying temperatures
textgen.generate(n=5, temperature=0.7)   # coherent
textgen.generate(n=5, temperature=1.2)   # drifting
textgen.generate(n=5, temperature=1.5)   # collapse
```

**Temperature guide:**
- `t=0.7` — more coherent, closer to training data rhythm
- `t=1.2` — drifting, associative
- `t=1.5` — at or near collapse; fragmented, minimal

### The Recursive Return
After generating poetry, the outputs were performed aloud to the trees — the author standing before the same trees that had been assigned EEG fragments, returning the machine-processed language to its non-human origin. The loop: `body → EEG → writing → fragments → trees → RNN → poetry → voice → trees`.

## Project 3: EEG with My Cat — Peerly × The Decameron (London, 2020)

### Concept
During COVID-19 lockdown, living in isolation with the cat Peerly, EEG sensors were attached to map his three most consistent daily activities: eating, sleeping, and playing. Each neural spike triggered a word from Boccaccio's *The Decameron* (1353) — chosen because its context of plague, enforced isolation, storytelling, and survival mirrored the crisis unfolding outside. The cat's quiet, cyclical rhythms became the generative engine for a body of poetry carrying traces of cross-species neural activity and fourteenth-century narrative.

### Hardware
- **EEG system**: PLUX biosignalsplux EEG sensor kit (same hardware as Immigrant and a Tree)
- **Software**: OpenSignals (PLUX)
- **Subject**: Peerly (domestic cat)

### Activity Classification
Three activity states were distinguished from EEG output:

| State | EEG Characteristics |
|-------|-------------------|
| Eating | Rhythmic, regular spike pattern |
| Sleeping | Low-amplitude, slow-wave activity |
| Playing | High-amplitude, irregular bursts |

EEG waveform signatures for each state are documented in the confirmation document (Figure 47).

### Corpus
- **Text**: *The Decameron* by Giovanni Boccaccio (1353), English translation (public domain)
- **Mapping**: Each detected EEG spike → next word drawn sequentially from the Decameron corpus, modulated by activity state

```python
# Simplified spike-to-word mapping
```

### Model
- **Architecture**: RNN (textgenrnn), char-level LSTM
- Trained on the spike-triggered word sequences from the cat EEG × Decameron mapping

### Output
- **40 poems** generated from Peerly's EEG neural data × Boccaccio's Decameron

- Context note: London, 2020, COVID-19 isolation

2. Open OpenSignals software; select active channels
3. Begin recording session

5. Parse in Python: EEG data is in the last column; earlier columns are sequence number and digital signals
6. Spike detection: threshold at `mean + 2.0 × std` (adjust multiplier for sensitivity)
7. Onset filter: discard spikes within 50 samples of previous spike to capture only onset events

## Conceptual Framework (for future technical decisions)

The following principles have guided all technical choices and should inform future EEG and OpenSignals work:

1. **Fragmentation is data, not error.** Incomplete outputs, stutters, and model collapse are treated as meaningful — preserve them rather than correcting for them.

2. **The body is a corpus.** EEG data is not just signal — it is corporeal autobiography. Technical decisions (spike threshold, sampling rate, channel selection) shape what of the body is legible.

3. **Temperature as poetics.** Generation temperature is an aesthetic parameter as much as a technical one. Document which temperature produced which poems.

4. **Collapse as ethics.** Models are not repaired or retrained when they begin to fail. Allowing collapse is a refusal of the logic of optimisation.

5. **The loop must close.** Each system returns its outputs to its origin: poetry is read back to trees; F0x's collapse is archived, not discarded; the machine's outputs re-enter the world that generated them.

## Notes for Future EEG Work

When returning to EEG and OpenSignals for future projects, the following workflow has been established:

### Session Setup
1. Charge biosignalsplux device fully before session
2. Electrode placement: follow standard 10-20 system or consistent custom placement — document placement for each session
3. Calibration: run 2–3 minute baseline recording before each session; use this to calculate per-session mean and std for spike detection
4. Multiple channels: channels 2, 3, and 5 were used in the 2019 performances; document which channels capture cleanest signal for your electrode placement

### Data Processing Pipeline
```python
from opensignals import load_session
import numpy as np

def process_eeg_session(filepath, spike_multiplier=2.0, min_gap=50):
    """
    Load and process a single OpenSignals EEG session.
    
    filepath: path to .txt OpenSignals export
    spike_multiplier: threshold = mean + multiplier * std
                      lower = more sensitive (more spikes)
                      higher = less sensitive (fewer, stronger spikes)
    min_gap: minimum samples between spikes (onset detection)
    """
    eeg = load_session(filepath)
    
    # Spike detection
    threshold = np.mean(eeg) + spike_multiplier * np.std(eeg)
    spike_indices = np.where(eeg > threshold)[0]
    
    # Onset filtering
    events = [s for i, s in enumerate(spike_indices)
              if i == 0 or s - spike_indices[i-1] > min_gap]
    
    return events

# Process multiple sessions
all_events = []
for session_file in session_files:
    events = process_eeg_session(session_file)
    all_events.extend(events)
```

### Corpus Preparation
```python
import nltk
from nltk.stem import PorterStemmer, WordNetLemmatizer

def prepare_corpus(raw_text):
    """
    Pre-process text corpus for RNN training.
    Consistent with F0x and dual-archive methodology.
    """
    stemmer = PorterStemmer()
    lemmatizer = WordNetLemmatizer()
    
    # Tokenise, stem/lemmatise as needed
    tokens = nltk.word_tokenize(raw_text.lower())
    processed = [lemmatizer.lemmatize(t) for t in tokens]
    
    return ' '.join(processed)
```
